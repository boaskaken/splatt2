# v1.3 acceptance testing

## Automated

Use Python 3.12 with Tcl/Tk and `python -m pip install -r requirements.txt`.

```
python -m unittest discover -s tests -v
python main.py --self-test smoke.json --gui
python -m pip install -r requirements-build.txt
python build/build.py
```

The self-test uses temporary data, prints and detects 4/6/8-marker sheets, renders all targets, checks audio/speech imports and, with `--gui`, tests the settings dialog. It does not open a camera, record audio or speak. The GUI tests also create the main window, apply settings and register a simulated shot without camera capture or audible speech. Tests cover atomic-save failures, old-key migration, invalid config, marker occlusion/duplicates/noise, serial speech, queue cancellation and microphone startup failure. The Windows CI job requires the GUI test and runs the same self-test against the packaged executable. A failed or timed-out check prevents artifact publication. Source tests do not replace testing the actual artifact.

## On the shooting PC

1. Launch from the integration checkout using RUN.bat; confirm v1.3 Community. Repeat with the packaged build when available.
2. Change voice, rate, volume and announcement mode. Use Test voice. Toggle Voice enabled, Apply & Close, reopen settings, then restart the app. Verify all choices persist.
3. Enter invalid rate, marker size and smoothing values. Apply must explain the error and keep the dialog open. Cancel must not save the invalid entries.
4. Start the camera and microphone. Confirm preview, aim, audio meter and target render. Test all six bundled targets, custom colours and labels, trace replay and digital zoom.
5. Present printed 4-, 6- and 8-marker sheets in Auto mode. Check the visible count and lower-bound wording. Cover markers; quality should drop and a temporarily reused position should be labelled. Restart the camera before switching to a sheet with fewer markers; that resets the Auto estimate.
6. Register several shots quickly. Speech must remain sequential. Disable speech while announcements are waiting; queued items should stop (the current utterance may finish). Prefer headphones so spoken announcements do not trigger the microphone.
7. Disconnect/reconnect the camera and microphone. Check the status message and data-folder log, then restart the camera. Check that scoring does not use an expired aim position.
8. Save a session, restart, reopen and replay it. Verify your calibration and physical sheet dimensions before assessing score accuracy.

## Local validation status

Hardware tests and listening tests are pending on the user's PC. In this execution environment, Tcl cannot initialise its startup files, including when using a separately extracted official Python/Tcl runtime. The source GUI tests are therefore skipped locally. A trial PyInstaller build exposed missing tkinter and failed its packaged GUI self-test; it is not a distributable release. The build now rejects this runtime early. Run the required Windows CI checks or build on a normal Python installation before distributing v1.3.
